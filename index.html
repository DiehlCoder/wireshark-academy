📋 Master Cybersecurity & Wireshark Cheat Sheet

        
      

      

        
1. Essential Wireshark Display Filters

        

          ip.addr == 10.10.10.20                 # Filter by IP endpoint
tcp.flags.syn == 1 && tcp.flags.ack == 0  # Initial connection attempts / SYN scans
tcp.flags.reset == 1                   # Closed port / connection abort (RST)
tcp.analysis.retransmission            # Packet loss / network degradation
arp.duplicate-address-detected         # ARP Spoofing / IP address conflict
http.request.method in {"GET","POST"}  # Web requests
dns.flags.rcode != 0                   # DNS resolution errors (NXDOMAIN)
ftp.request.command in {"USER","PASS"} # Plaintext FTP credentials
        


        
2. BPF (Capture Filter) Quick Reference

        

          host 10.10.10.20                       # Inbound & outbound to IP
src net 10.10.10.0/24                  # Source inside subnet
port 53 or port 80                     # Filter on port numbers
not port 22                            # Exclude SSH administrative traffic
ether proto 0x0806                     # Capture ARP packets only
        


        
3. Nmap Scanning Syntax

        

          nmap -sn 10.10.10.0/24                 # Host discovery ping sweep
nmap -sS -p- -T4 10.10.10.30           # Fast SYN stealth scan all 65,535 ports
nmap -sV -sC -O 10.10.10.30            # Service version, default scripts & OS detection
nmap --script vuln -p 80 10.10.10.20   # Vulnerability scan web service
